# NusaTrip — Travel & Tourism Website

Modern, responsive tourism portfolio concept for an Indonesian travel brand.

## Preview
- Live preview (when GitHub Pages is enabled): https://uknowdream.github.io/
- Source: https://github.com/uknowdream/uknowdream/blob/main/index.html

## Highlights
- Editorial hero with destination search
- Destination cards with favorite interactions
- Curated travel packages and pricing
- Responsive mobile navigation
- Newsletter demo form and accessible status feedback
- Semantic HTML, responsive CSS, reduced-motion support, lazy-loaded images
- No build step or framework required

## Run locally
Open index.html in a browser. External Google Fonts and Unsplash images require an internet connection.

## Important demo notes
NusaTrip is a fictional portfolio concept. Prices, ratings, testimonials, and travel statistics are illustrative and must be verified/replaced before commercial use. Search and newsletter interactions are front-end demonstrations; no booking, payment, email service, or CRM is connected.

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript
